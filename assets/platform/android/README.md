# Android icon resources

The `res` directory is a drop-in adaptive-icon resource set. Its 49dp foreground
mark sits comfortably inside Android's 66dp safe zone on a 108dp canvas and includes a dedicated
monochrome layer for themed icons. `ic_splash_icon.xml` is the teal-on-transparent
splash-screen mark, while `ic_notification.xml` is a white-on-transparent notification silhouette.

The same generated resources are integrated into `src/android/app/src/main/res`.
