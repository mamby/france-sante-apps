# Windows / WinUI application icons

`Assets` contains scale-qualified MSIX resources for `Square44x44Logo`,
`Square150x150Logo`, and the required package `StoreLogo`, plus all current
app-list target sizes. Dark-theme unplated variants use the soft-white mark;
light-theme unplated variants use teal.

`AppIcon.ico` contains 16, 24, 32, 48, and 256px frames for an unpackaged WinUI
window or other Win32 icon consumers. Store promotional banners are not included.
