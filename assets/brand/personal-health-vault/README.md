# Folded square identity

The approved Personal Health Vault mark is a rounded square crossed by a single
flowing negative-space seam. The geometry is intentionally abstract: it suggests
continuity and a protected personal space without using medical or security
clichés.

## Source files

- `source/app-icon.svg`: full-bleed teal application icon master.
- `source/mark-teal.svg`: primary mark on transparency.
- `source/mark-reversed.svg`: soft-white mark on transparency.
- `source/mark-monochrome.svg`: single-color production master.
- `source/palette.json`: canonical color values.

Keep the mark proportions and seam geometry unchanged. Platform masks may alter
the outer app-icon container, but must not alter the inner Folded square mark.
